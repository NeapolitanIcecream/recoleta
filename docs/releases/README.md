# Release archive

The versioned draft, launch-kit, and content-pack files in this directory record
what was prepared for their named historical releases. They may preserve
positioning, screenshots, setup paths, or claims that are no longer current.
Do not copy them into a new release without revalidation.

Current release work starts here:

1. [`release-process.md`](./release-process.md) — release gates and artifact
   procedure.
2. [`github-launch-handoff.md`](./github-launch-handoff.md) — current repository
   surface and execution checklist.
3. [`../promotion/status.md`](../promotion/status.md) — live promotion state and
   approval gates.
4. [`../promotion/channel-kit.md`](../promotion/channel-kit.md) — current draft
   release and channel copy.

Historical ADRs and changelog entries describe decisions and behavior at their
original dates; they are not silently rewritten as current product intent.
