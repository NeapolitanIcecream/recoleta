# Promotion research baseline

Snapshot date: 2026-07-25

This file records the evidence behind the current strategy. Counts and platform
rules are dated observations, not permanent facts.

## Repository and product

Observed locally:

- Recoleta is at version `0.6.1`, with eight public GitHub Releases from `v0.1.0`
  through `v0.6.1`.
- The repository contains a mature fleet runtime, SQLite persistence, rebuildable
  publishing projections, and hundreds of tests.
- The production fleet has three isolated streams: `embodied_ai`,
  `software_intelligence`, and `cross_platform`.
- A successful 2026-07-23 production validation used Recoleta `0.6.1` and Huldra
  `0.4.1`, deployed the fleet site, and verified current English and Chinese
  trend pages.
- At the start of the sprint, the README led with `Local-first AI research
  radar`, source checkout, a five-minute claim that had not been cold-user
  validated, and screenshots created before the current site redesign.

Owner clarification:

- Much of the older documentation was generated by earlier AI systems and is not
  authoritative product intent.
- The product has been developed from sustained use by the maintainer and their
  team, but team identity and endorsement language are not public by default.
- `local-first` is not the maintainer's central product claim.

## Evidence semantics

Confirmed in code:

- retained Idea references are constrained to exact successfully read chunks and
  at least two distinct item documents;
- Trend evidence is constrained to exact reads and configured document support;
- a one-document corpus may retain one explicitly marked single-source Trend;
- insufficient windows can be suppressed rather than expanded into filler.

Limit:

- an exact read trace proves that a chunk was read and attached; it does not
  prove that every generated sentence is entailed by that chunk;
- the internal frozen-sample quality review was non-blind, post-hoc, and small,
  so it is directional evidence rather than a comparative product benchmark.

## Comparable mechanisms

Comparable open-source research tools suggest a reusable sequence:

1. direct package or image installation;
2. a visible real output and short demonstration;
3. reproducible evidence or a candid benchmark;
4. persistent documentation and owned distribution;
5. community surfaces after activation friction is controlled.

Examples:

- <https://github.com/Future-House/paper-qa>
- <https://github.com/LearningCircuit/local-deep-research>
- <https://github.com/reorproject/reor>
- <https://github.com/khoj-ai/khoj>
- <https://github.com/MODSetter/SurfSense>

These examples show mechanisms, not causal proof that a particular channel
created their adoption.

## Current platform constraints

- Hacker News requires the maker to be present and prohibits generated or
  AI-edited comments:
  <https://news.ycombinator.com/showhn.html> and
  <https://news.ycombinator.com/newsguidelines.html>.
- Bluesky permits scheduled bots, recommends a bot self-label, and requires
  automated interaction to be opt-in:
  <https://docs.bsky.app/docs/starter-templates/bots>.
- `mastodon.social` does not allow accounts that solely post AI-generated
  content:
  <https://mastodon.social/auth/sign_up>.
- Google recommends sitemaps for discovery but warns against scaled generated
  pages that do not add user value:
  <https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview>
  and
  <https://developers.google.com/search/docs/fundamentals/using-gen-ai-content>.
- Package-download counts may include mirrors, caches, and automated clients and
  are not a product-quality or activation measure:
  <https://packaging.python.org/en/latest/guides/analyzing-pypi-package-downloads/>.

## Release-readiness recheck

Observed later on 2026-07-25:

- PyPI's JSON API reported `huldra-arxiv 0.4.1`; the earlier `0.2.0` rendered
  page observation was stale or incomplete.
- PyPI's JSON API returned HTTP 404 for `recoleta`.
- A pending PyPI Trusted Publisher can create a new project on its first
  successful publication, but it does not reserve the project name:
  <https://docs.pypi.org/trusted-publishers/creating-a-project-through-oidc/>.
- A GitHub Actions publisher must match owner, repository, workflow filename,
  and, when configured, environment. PyPI strongly recommends the environment
  as an additional restriction:
  <https://docs.pypi.org/trusted-publishers/adding-a-publisher/>.
- GitHub's container registry makes a new package private by default. A public
  container can be pulled anonymously, and changing a package to public cannot
  be reversed:
  <https://docs.github.com/en/packages/learn-github-packages/configuring-a-packages-access-control-and-visibility>.
- Changelog News explicitly accepts self-submitted open-source work and asks
  submitters to explain why it is newsworthy:
  <https://changelog.com/news/submit>.
- PyCoder's Weekly explicitly accepts Python community projects for editorial
  consideration:
  <https://pycoders.com/submissions>.

## Local intervention evidence

Verified on 2026-07-25 after the implementation and discovery refactor:

- Recoleta passed Ruff, Pyright, and all 1,047 tests.
- Cremona reported no new or worsened structural debt after the site discovery
  work was split by metadata, language, feed, sitemap, robots, and export
  orchestration axes.
- The full isolated production-fleet build emitted 5,284 HTML pages and 8,999
  total files.
- Its discovery surface contained 986 curated sitemap URLs, English and Chinese
  Atom feeds, canonical and language-alternate links, and 4,298 intentionally
  non-indexable pages.
- The Recoleta `0.6.1` wheel and source distribution passed Twine checks. A
  fresh Python 3.14 environment installed the built wheel and produced the
  bundled no-key fleet demo without network or model calls.
- The rebuilt default container passed CLI, doctor-help, bundled-demo, and
  bundled-Huldra smoke checks.
- The redacted three-child fleet dry-run now plans from read-only or in-memory
  state and creates no configured SQLite databases or example `.state`
  directory.
- Huldra `0.4.2` passed Ruff, Pyright, all 274 tests, wheel and source
  distribution builds, and Twine checks.

These are local release-readiness facts, not evidence of external adoption.
No channel submission or external activation occurred during this checkpoint.
